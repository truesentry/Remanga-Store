# Remanga-Store
Інтернет-магазин манги, манхви та маньхуа

Технології
- Python / Django
- Bootstrap 5
- SQLite
- JavaScript (AJAX)

Функціонал
- Каталог товарів з фільтрацією
- Пошук з автодоповненням
- Реєстрація та авторизація
- Додавання в обране
- Відгуки та рейтинг
- Hero-слайдер на головній

 Як запустити проєкт
bashgit clone https://github.com/truesentry/Remanga-Store
cd django_project
source venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
